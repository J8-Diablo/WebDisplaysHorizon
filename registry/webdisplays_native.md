
## Description

```markdown
**WebDisplays Native** is the code half of WebDisplays, the mod that puts working web
browsers on screens in your world. It does everything the mod does: showing the pages,
clicks and typing, sound, light.

## It is one of three

WebDisplays for Horizon comes in three parts, and it needs all of them:

- **WebDisplays** (`webdisplays`): the blocks and items.
- **WebDisplays Native** (`webdisplays_native`): this one, the code.
- **HCEF** (`hcef`): the browser. Without it the launcher refuses to build this mod.

Install the three, build, then download the browser once from **Options > Mods > HCEF** in
the game. The **WebDisplays Pack** modpack installs the three together.

## What it does

- Screens made of blocks, and screens traced with the stylus, flat or with rounded corners.
- Keyboard, remote control, redstone controller, linking tool, laser pointer, MinePad.
- One page over several screens, or one browser shown on several screens.
- Sound that follows the place: echo in a room, muffled behind a wall. Speakers.
- Light from the screens on what is around them.
- YouTube and Twitch addresses open as full-frame players, live streams included.

## Good to know

- Windows x64 only for now, and an early version.
- Each player's own computer plays the page: videos are not synchronized between players.
- Like every native mod, it is not sandboxed. The source is in the repository.
```
